# Короткий обзор существующих решений

Обзор по публичным описаниям, 3 ноября 2026 года; это первичное исследование, не аудит кода, безопасности или активности поддержки. Интеграцию и лицензии перед использованием надо проверить отдельно.

| Решение | Что интересно | Ограничение для этого проекта |
| --- | --- | --- |
| [Ateam](https://github.com/clawnify/ateam) | Claude/Codex, задачи, worktree, PTY и несколько терминалов | Публичное описание и установка ориентированы на macOS; worktree — центральная модель. Windows и корпоративный GitLab не подтверждены. |
| [ProPR](https://github.com/integry/propr) | Самостоятельный хостинг, несколько агентов, ревью и исправления; Apache-2.0 | Процесс ориентирован на GitHub PR и Docker-контейнеры; это другая отправная точка. |
| [Horde](https://github.com/gethamster/horde) | Локальное устойчивое управление задачами и несколькими агентами | В описании указаны macOS/Linux; другой основной интерфейс. Применимость к Windows и встроенному терминалу не подтверждена. |
| [agent-orchestrator](https://github.com/azweb76/agent-orchestrator) | Локальная веб-панель, worktree и управление агентами | Описание ориентировано на GitHub и Claude; независимое ревью Codex и корпоративный GitLab нужно проверять. |

Предварительный выбор: небольшая собственная реализация, поскольку ни один вариант пока не доказал, что проще закрывает Windows, GitLab/GitHub, текущий checkout, интерактивный терминал и независимое ревью. Это не утверждение, что существующие проекты не умеют эти вещи. До написания большого объёма кода стоит повторно оценить Ateam и другие решения по лицензии, последним релизам, архитектуре, Windows и возможностям расширения; при обнаружении подходящей основы решение можно изменить.
