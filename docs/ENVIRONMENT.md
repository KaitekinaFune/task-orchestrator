# Проверка среды Windows

Результаты пробного запуска 3 ноября 2026 года в ограниченной среде агента; на другой машине и вне этой среды результаты могут отличаться. Секреты и содержимое учётных записей не сохранялись.

- Node.js `v24.22.1`, Bun `1.4.4`, Git `2.55.0.windows.5`, Claude Code `2.1.317`, Codex CLI `0.166.0-alpha.5.1` обнаружены в PATH.
- `claude auth status --json` сообщил `loggedIn: false` для обычного запуска. Пользователь отдельно использует `claude-sub` и `claude-litellm`; эти имена не обнаружены через `Get-Command` в текущем процессе PowerShell. Их определения и авторизация не проверены, поэтому статус обычного запуска к ним не применяется. Вызов модели Claude не проверен.
- `codex login status` завершился с кодом 0. Это не подтверждает работоспособность обращения к модели: пробный `codex exec --ephemeral --sandbox read-only --skip-git-repo-check` завершился с кодом 1 из-за отказа в доступе при инициализации app-server и базы состояния в ограниченной среде.
- Справка Claude описывает `--print` и потоковый `--output-format stream-json`; справка Codex — `exec`, `--json` и `--output-schema`. Фактические протоколы, обработка разрешений и результат вызова ещё требуют проверки; небезопасные флаги обхода разрешений не использовались.
- Пробная установка `node-pty` через `bun add` завершилась ошибкой `EBADF accessing temporary directory`, в том числе при заданном `BUN_TMPDIR` внутри рабочего каталога. Зависимость не установлена, ConPTY и интерактивный обмен не проверены. Это не доказывает несовместимость Bun или node-pty с Windows вне данной среды.

## Следующие проверки

На доверенной машине с доступом к обычным каталогам пользователя повторить установку и проверить ввод, вывод, изменение размера и завершение PowerShell через PTY под Node.js. Отдельно проверить авторизацию и минимальный неинтерактивный вызов каждого CLI, не записывая секреты. Для проверки Git и профилей команд создать отдельный небольшой тестовый репозиторий; команды проверок должны быть явно заданы пользователем. До успешного выполнения этих проверок не считать ни интеграции CLI, ни терминал работающими.
