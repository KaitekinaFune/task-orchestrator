Подключить репозиторий

Подключай только репозитории, которым доверяешь: агенты запускаются в них без отдельного подтверждения и могут загрузить их настройки, hooks и MCP. Удаление проекта убирает только записи приложения: файлы репозитория остаются на месте.

    Команда

    Для обычной работы здесь больше ничего настраивать не нужно. Супервизор сам выбирает, кого из отмеченных агентов и как задействовать в каждой задаче. Он работает без инструментов, а агенты работают по обычным правилам CLI.

    Воркеры

    Codex

    Используется авторизация установленного Codex CLI. Пишущий воркер — workspace-write, остальные роли — read-only; дополнительные права не выдаются.

    Корпоративный LiteLLM

    Параметры сохраняются локально. Ключ сохраняется отдельно в Windows Credential Manager и не отображается после сохранения.

    Личный DeepSeek

    Настройки независимы от LiteLLM; ключ хранится в отдельной записи Windows Credential Manager.

    Профили Claude

    Настройте имена переменных LiteLLM: по одной паре на строку в формате ИМЯ_CLAUDE=ИМЯ_В_ОКРУЖЕНИИ_СЕРВЕРА. Строка с одним именем означает только очистку. Значения, включая ключи, сюда не вводятся. Укажите все переменные, которые очищает профиль подписки.

    Переменные источника должны существовать в окружении до запуска сервера. После изменения их значений перезапустите сервер.
