Проекты

Подключи репозиторий, настрой команды проверок и выбери, какие из них запускает каждый процесс.

Подключить репозиторий

Подключай только репозитории, которым доверяешь: агенты запускаются в них без отдельного подтверждения и могут загрузить их настройки, hooks и MCP. Удаление проекта убирает только записи приложения: файлы репозитория остаются на месте.

    Процессы

    Исполнитель, модель, инструкции и независимое ревью. Один процесс можно использовать в любом проекте.

    Кто что делает, выбирается свободно: исполнитель, ревьюер и агент исправлений — любой агент, профиль и модель. Ревьюер всегда работает в отдельной сессии и только на чтение. По умолчанию один проход; при необходимости включи ограниченные автоматические исправления ниже. Если этого мало, выбери в этапах свой граф шагов.

    Новый процесс

    Граф шагов

    Необязательно: для обычной задачи достаточно одного агента. Граф нужен, когда над задачей работают несколько ролей: гейм-дизайнер, продюсер, отдельный агент исправлений, подтверждение человека. Следующий шаг определяют результаты проверок и заключения, а не текст агента.

    Какие проверки запускать, выбирается для каждого проекта в разделе «Проекты». Пока выбор не сделан, запускаются все проверки проекта.

    Ревьюер

    Любой агент: отдельная сессия, только чтение. Проверки можно не выбирать; отсутствие проверок будет явно отмечено.

    Автоматические исправления

    После каждого исправления повторяются проверки и ревью. Неполное ревью, ошибки запуска, отсутствие прогресса и повторяющиеся проблемы требуют твоего решения. Права CLI не меняются.

    Подключения

    Профили Claude Code, Codex и настройки провайдеров.

    Codex

    Используется авторизация установленного Codex CLI. Модель задаётся в процессе. Исполнитель — workspace-write, ревьюер — read-only; дополнительные права не выдаются.

    Корпоративный LiteLLM

    Параметры сохраняются локально. Ключ сохраняется отдельно в Windows Credential Manager и не отображается после сохранения.

    Личный DeepSeek

    Настройки независимы от LiteLLM; ключ хранится в отдельной записи Windows Credential Manager.

    Профили Claude

    Настройте имена переменных LiteLLM: по одной паре на строку в формате ИМЯ_CLAUDE=ИМЯ_В_ОКРУЖЕНИИ_СЕРВЕРА. Строка с одним именем означает только очистку. Значения, включая ключи, сюда не вводятся. Укажите все переменные, которые очищает профиль подписки.

    Переменные источника должны существовать в окружении до запуска сервера. После изменения их значений перезапустите сервер.
